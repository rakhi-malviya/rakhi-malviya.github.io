Rakhi Malviya Portfolio
=======================

Files:
- index.html: page content and navigation
- style.css: all visual styling and responsive behavior

Optional assets:
- Add your profile image at assets/images/profile.jpg when ready.
  Then replace the decorative .profile-placeholder block in index.html
  with an img element using src="assets/images/profile.jpg" and suitable alt text.
- Add your resume as assets/documents/resume.pdf when ready, then add a
  download link in the hero or contact section.

Preview:
Open index.html directly in a modern browser.

Technology:
HTML5 and CSS3 only. No JavaScript or frameworks.
The contact email link opens the visitor's email application. There is no
message-processing contact form because that requires a backend or external
form service.
